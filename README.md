# Norse Mythology Nine Realms Flashcards

Study Norse gods, realms, creatures, and events from Yggdrasil to Ragnarök through interactive spaced repetition flashcards.

## Features
- 30+ cards covering all Nine Realms, major gods (Odin, Thor, Loki, Freya), creatures, artifacts, and key events
- Flip animation flashcards with category badge and difficulty stars
- Category filter: Gods, Realms, Creatures, Artifacts, Events, Concepts
- Spaced-repetition rating: Again / Hard / Known
- Progress tracking with colour-coded card index
- Keyboard navigation: Arrow keys to navigate, 1/2/3 to rate, Enter/Space to flip
- Shuffle mode for randomized study order
- localStorage persistence of progress

## Usage
1. Select a category to focus your study, or study All cards
2. Read the name on the front of the card
3. Try to recall the description before flipping
4. Click (or press Enter/Space) to reveal the full description and key connections
5. Rate your recall: Again (1) / Hard (2) / Known (3)
6. Track progress in the card index at the bottom

## Tech
